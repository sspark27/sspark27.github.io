# 갤러그 분석 및 구현 기준

## 근거

- Bandai Namco 공식 게임 설명: https://galaga.com/ja/history/galaga.php
- 공식 영어 설명: https://galaga.com/en/history/galaga.php
- 개발자 인터뷰: https://galaga.com/en/special/int_vol1.php
- Nintendo 배포 매뉴얼: https://www.nintendo.co.jp/clv/manuals/en/pdf/CLV-P-NABNE_en.pdf

공식 설명에서 확인한 축은 좌우 이동, 화면상 발사 수 제한, 화면 밖에서 진입하는 40기 편대, 보스·고에이·자코 세 종류, 포획 빔, 구출 후 두 배 화력과 넓어진 피격 범위, 별도 챌린징 라운드다. 자동 발사는 사용자의 요구로 변경한다. 원작 ROM이나 프레임별 계측 자료를 사용하지 않았으므로 정확한 좌표·타이밍·난수·히트박스까지 동일하다고 주장하지 않는다.

## 전투 구조

진입 → 정렬 → 호흡하듯 움직이는 편대 → 일부 적의 루프/급강하 → 화면 밖 복귀 → 재정렬을 반복한다. 플레이어는 적의 진입 단계에서도 격추할 수 있다. 무조건 피해 다니는 대신 급강하 격추의 높은 점수와 포획 구출의 화력 증가를 노리도록 설계한다.

40기는 보스 4, 고에이 16, 자코 20으로 배치한다. 보스만 내구도 2이며 첫 피격 후 색이 바뀐다. 보스는 가까운 고에이 두 기까지 함께 급강하한다. 점수는 자코 50/100, 고에이 80/160, 보스 150/400 + 출격 당시 호위기당 400으로 설정한다. 원작의 호위 격추 순서별 정밀 보상 판정은 간소화했다.

일반 보스는 전방으로 이동한 후 부채꼴 빔을 전개한다. 자동 발사가 포획을 항상 방해하지 않도록 빔 준비/전개 중 보스에는 탄이 통과한다. 포획은 예비 기체를 소모하고, 이후 급강하 상태의 보스를 격추하면 듀얼로 복구한다. 편대에서 격추하면 포획 기체가 적으로 남는 단순화된 실패 규칙을 적용한다. 마지막 기체의 강제 포획은 막는다.

급강하 간격은 2.7초에서 0.72초로 감소하며, 발사 확률은 0.28에서 0.865로 증가한다. 챌린징 스테이지는 공격을 쉬는 대신 더 빨라지는 곡선 비행을 제한된 발사 묶음으로 맞혀야 한다. 보너스 구간 때문에 생존 위험이 매 스테이지 단조 증가하지는 않으며, 일반 전투의 압박과 보너스의 조준 난도는 각각 상승한다. 10스테이지 완료 후 승리 화면과 최종 점수를 제공한다.

## 구현 범위와 차이

원작의 일반 편대 전투·급강하·포획/구출·듀얼·보너스 라운드를 재구현했다. 요청에 따라 자동 발사, 세 가지 입력 방식, 오프라인 HTML5 실행, 10단계 완결 구조를 적용했다. 독자적인 도트 패턴과 Web Audio 합성음, 스테이지 클리어 보상, 현대적인 주변 UI를 사용했다.

원작의 모든 진입 궤적, 변신 적/특수 편대, 숨겨진 버그, DIP 난이도·잔기 설정, 2인 교대, 원곡, ROM 스프라이트와 프레임 단위 동작은 재현 범위에 포함되지 않는다. 완벽한 에뮬레이션과 구별되는, 원작의 핵심 전투 구조를 바탕으로 한 웹 게임이다.

렌더링은 480×640 Canvas와 정수 도트 패턴, 시뮬레이션은 120Hz 고정 간격이다. 외부 이미지·폰트·라이브러리·fetch·모듈 로딩을 사용하지 않아 file://에서도 실행할 수 있다. Gamepad API와 전체 화면은 브라우저의 지원과 권한 정책에 따른다.
