# GALAGA · 10 Stage Arcade

`index.html`을 더블 클릭하여 브라우저로 열면 실행됩니다. 설치, 빌드, 서버, 인터넷 연결이 필요하지 않습니다. `index.html`, `style.css`, `engine.js`, `game.js`를 같은 폴더에 보관하세요.

- 시작 / 재도전: Enter 또는 화면 버튼. 게임패드 A / Start.
- 이동: ← →, A D, 화면 위 마우스 이동, 터치 드래그, 게임패드 왼쪽 스틱 / 십자키.
- 무기: 자동 발사. 화면에 최대 두 발사 묶음, 듀얼은 묶음당 두 발.
- 일시정지: P / Esc 또는 게임패드 A / Start. 창을 벗어나면 자동으로 정지합니다.
- 사운드: M 또는 SOUND 버튼. 처음에는 음소거이며, 켜면 합성 효과음이 재생됩니다.
- 전체 화면: 하단 ⛶ 버튼. 브라우저가 지원하는 경우에만 동작합니다.

게임패드는 연결 후 버튼을 한 번 눌러 브라우저에 인식시키세요. 표준 매핑의 패드를 기준으로 구현했습니다. 브라우저에 따라 `file://`에서 Gamepad API를 제한할 수 있습니다. 이 경우 아래 로컬 서버를 이용하세요. 최고 점수는 localStorage 사용이 허용될 때 저장되며, 제한된 경우에도 게임은 동작합니다.

선택적 로컬 서버: Node.js가 있다면 `node serve.cjs`, 그다음 `http://localhost:4173`을 여세요. 서버는 이 컴퓨터에서만 접근 가능합니다.

총 10스테이지, 시작 시 기체 3대. 20,000점에서 추가 기체, 이후 70,000점마다 추가 기체를 얻습니다. 3·7스테이지는 40기 보너스 비행입니다. 보너스 라운드의 적은 공격하지 않으며 격추당 100점과 결과 보너스(격추당 100점, 전멸시키면 대신 10,000점)를 얻습니다. 일반 스테이지 클리어는 스테이지 번호 × 500점입니다.

보스의 빔 안에 머물면 기체가 포획되며 예비 기체 한 대로 다시 출격합니다. 포획 기체를 거느린 보스를 **급강하 중** 격추하면 듀얼 파이터가 됩니다. 편대에 있을 때 보스를 격추하면 포획 기체가 적이 되므로 타이밍에 주의하세요. 듀얼 상태에서 피격되면 싱글로 돌아갑니다. 기체가 한 대만 남으면 포획하지 않습니다.

구현 분석과 원작 대비 변경사항은 `ANALYSIS.md`를 참조하세요. 이 구현은 독자적으로 작성한 코드·픽셀 패턴·합성음을 사용하는 비공식 재구현이며 원작 ROM의 프레임 단위 복제본은 아닙니다.

검증: `node --test tests/*.test.cjs`. 실제 검증 범위는 `VALIDATION.md`를 참조하세요.
